# 掌上酒馆快速上手

[返回首页](../README.md) · [English guide](quick-start.en.md)

## 安装与更新

在 [最新版发布页](https://github.com/wacilimonster-source/pockettavern/releases/latest) 的 Assets 中下载 `pocket_tavern_版本号.apk`，在 Android 手机上安装。已有用户可以覆盖安装，App 内更新入口为「设置 → 通用 → 检查更新」。

## 远程模式

准备一个已运行、手机能够访问的 SillyTavern 服务端，以及角色卡与可用的模型服务配置。

1. 先在手机浏览器中打开服务端地址，确认网络可达。
2. 打开掌上酒馆，在欢迎页输入相同地址并连接。局域网示例为 `http://192.168.1.100:8000`，请替换为自己的地址。
3. 进入「角色」，点选角色，打开已有对话或点击「新建对话」。
4. 在「设置 → AI 服务」核对生成源、模型和配置。当前提供 DeepSeek、GEMINI网关、OpenCode Go、自定义四种入口。
5. 发送消息，等待流式回复。消息操作中可以编辑、重新生成、继续生成或切换变体。

远程模式的聊天文件保存在 SillyTavern 服务端。

## 本地模式

首次准备包括一个可访问的 SillyTavern 数据源，以及可用的模型服务地址、模型名称和所需 Key，或 GEMINI网关连接信息。

1. 在欢迎页点击「先在本机开一间」，进入本地模式。已进入应用时，也可以通过设置中的运行模式开关切换。
2. 打开「设置 → 远程数据源」，添加自己的 SillyTavern 地址，也可以从已连接过的服务器中选择。
3. 打开数据源，查看角色、对话、世界书和配置等分类中的差异，勾选需要的项目并同步到本机。涉及覆盖时，核对 App 显示的差异与确认信息。
4. 打开「设置 → AI 服务」，选择生成源。自定义服务填写相应地址、Key 和模型名称；网关源进入网关设置填写连接信息。
5. 返回「角色」，打开已同步的角色，创建或继续一段对话。

完成资料同步后，角色卡、对话和世界书使用本机资料，模型请求从手机发往所配置的模型服务。后续可以再次进入远程数据源查看资料差异。

## 按用途找到设置

| 想做的事 | 入口 |
| --- | --- |
| 配置生成源、地址、Key 和模型 | 设置 → AI 服务 |
| 选择和管理预设 | 设置 → 预设 |
| 配置人设与提示词 | 设置 → 提示词与人设 |
| 查看、编辑和启用世界书条目 | 设置 → 世界书，或聊天页的世界书入口 |
| 切换深色、浅色或跟随系统 | 设置 → 界面与显示 |
| 查看版本和检查更新 | 设置 → 通用 |

## 遇到问题时

- **看不到角色**。核对当前运行模式。远程模式检查服务端连接，本地模式查看远程数据源的角色同步结果。
- **可以看到角色但生成失败**。核对生成源、模型、Key 与服务地址，并记录错误提示。模型请求的可达性与额度由所用模型服务决定。
- **复杂卡片或脚本表现异常**。记录触发步骤与涉及的扩展功能，整理可以复现问题的最小示例。
- **需要协助**。前往 [Issues](https://github.com/wacilimonster-source/pockettavern/issues/new)，提供 App 版本、Android 版本、运行模式、复现步骤与截图，并移除密钥和个人信息。
